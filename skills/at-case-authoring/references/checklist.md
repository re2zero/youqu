# 合规检查清单

检查模式逐项核对。每项给出违规示例与正确写法。

## 1. 列级

- [ ] 标题格式：自动化用例 `【模块】功能_场景`；manual 用例 `【人工】功能_场景`（见 spec §2/§7）
  - 违规：`最小窗口-检查最小窗口680*510`（无【模块】前缀）
- [ ] 前置条件是否只含**状态**（可断言），无动作句
  - 违规：`1.首次打开日历管理页面`（这是动作）
  - 正确：`已有 3 个日程；网络连接正常`
- [ ] 步骤每行是否**恰好一个动作**，格式 `动词 + UI目标 + 参数`
  - 违规：`2. 观察文本编辑区域的高亮选中状态`（以观察开头，是断言）
- [ ] 预期是否每行一个**可断言目标**
  - 违规：`1. 操作正常` / `1. 无异常`

## 2. 步骤内容

- [ ] 步骤中**不含**断言词：检查/确认/查看/验证/是否/应该/符合/出现/消失/正确/可见/观察/对比（命中会被解析器判为断言）


- [ ] 步骤每行不包含分号拼接的多动作
  - 违规：`正确填写收件人、主题、正文，正文包含附件字样；不添加附件`
- [ ] 步骤不以非动词开头（`符合搜索的内容`、`没有对应搜索内容时` 都是状态描述，不是操作）

## 3. 输入数据

- [ ] 无 `输入任意字符` / `输入很长的字符` / `输入任意长度字符` 类占位
- [ ] 输入内容不包含描述词：显示/被清空/可以重新/正常/异常/检查/查看/应当/应该
  - 违规：`输入：正常内容` → 正确：`输入：test_content_001`
- [ ] 边界/超长输入给了具体字符数

## 4. UI 目标引用

- [ ] 目标写的是**屏幕可见文本**，不是位置描述或代码标识
  - 违规：`点击右上角的"替换"`（无文本）、`点击空白处`、`点击 Search 元素`、`accessible_id=FindNext`
  - 例外：DDropdownMenu 下拉菜单项写功能描述（如 `切换行尾格式为 Windows`），
    element-map 填 `object_name` → 映射阶段转 `selector.accessible_id`
- [ ] 无文本控件写的是**从属容器 + 位置**
- [ ] 菜单写的是**路径**：`右键-查找` / `主菜单-设置-高级设置`

## 5. 状态/时序

- [ ] 时序操作拆成了独立步骤（不是揉成一句）
  - 违规：`输入内容后检查结果`
- [ ] "过程中"类步骤标了 `[时序敏感]`
- [ ] 每个 `等待<秒>` 后都有后续断言

## 6. 不可自动化目标

- [ ] 断言目标是否命中 spec §7 的 8 类不可自动化类别（颜色/高亮/光标/tooltip/系统环境/外部硬件/文件网络/性能/跨应用）
- [ ] 命中类别 → 标题标 `【人工】` **且** `manual: true`（两者必须同时，见 spec §7）
- [ ] 前置条件含无法自动构造的状态（U盘/网络/登录）→ 前置标 `[手工]` 且 `manual: true`
- [ ] 不使用 `【外部】` 前缀（统一 `【人工】` + reason 注明类别）

## 7. 界面元素映射表

- [ ] `id_name`/`object_name` **至少填一个**：仅 setAccessibleName 填 `id_name`
      （selector.name）；QAction/DAction 等无 setAccessibleName 填 `object_name`
      （selector.accessible_id，Qt6 编码进 accessible_id 后缀）；两者都有都填，
      映射阶段有 object_name 优先用 accessible_id
- [ ] QAction/DAction 的 `object_name` 填 objectName（Qt6 编码进 accessible_id
      后缀）；**不填 menu_type 字段**——executor 运行时按 popup aid 段
      自动分类触发方式
- [ ] 关闭态无节点 / 无 object_name 编码的 QMenu 右键菜单项（如 CloseTab、
      大写/小写）标记 role=menu，用例用 `dtk_context_menu` + 右键触发点 +
      items；未被误标为持久（不进分母）

## 8. 语义保持（转换校对）

- [ ] 对照 `raw_*` 字段确认：AI 规范化未改变用例语义（标题/步骤/预期与原始描述一致）

> 说明：`id` 与原始行号对应、转换数量相等是**转换流程**的完整性校验（由 `convert_xlsx.py` 保证并记录 case_count），不属于用例合规检查项。
