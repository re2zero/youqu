# AT-SPI YAML 测试管线使用指南

## 概述

`youqu at` 命令族提供完整的 AT-SPI YAML 测试自动化管线，从源码扫描到用例执行，覆盖 Linux 桌面应用（DTK/Qt）的 UI 自动化测试全流程。

### 管线全景

```
scan → record → merge → tree-info → precandidate → validate → generate → run
         ↑                                                    ↑
       plan (按模块编排录制计划)
```

两种工作流模式：

- **全量模式**：一次性处理所有用例，适合小项目快速验证
- **按模块模式**（推荐）：`plan` 生成模块计划，逐模块 record → merge → generate → verify，适合大型项目

## 环境准备

### 系统依赖

```bash
# libclang（源码扫描）
sudo apt install python3-clang-18 libclang-18-dev

# AT-SPI（运行时树抓取）
sudo apt install at-spi2-core python3-pyatspi

# X11 录制（被动监听，不干扰用户操作）
pip install python-xlib

# Wayland 录制（低精度模式）
pip install evdev

# GUI 录制（可选，PyQt6 浮动窗口）
pip install PyQt6
```

### 安装 youqu

```bash
pipx install youqu-ai
# 或开发模式
pipx install -e /path/to/youqu
```

### 验证环境

```bash
youqu at scan --help    # 确认命令可用
python3 -c "import clang.cindex; print('clang OK')"
python3 -c "import pyatspi; print('AT-SPI OK')"
```

## 命令详解

### 1. scan — 源码静态扫描

用 libclang 扫描 C++ 源码，提取 UI 控件骨架：类继承、objectName、accessibleName、QAction 文本、.ui 文件、.ts 翻译。

```bash
youqu at scan \
  --src /path/to/app/src \
  --app my-app \
  --output tests/at \
  --target-lang zh_CN \
  --compile-commands /path/to/build/compile_commands.json
```

**参数**

| 参数 | 必填 | 说明 |
|------|------|------|
| `--src` | 是 | 源码根目录 |
| `--app` | 是 | 应用 ID |
| `--output` | 否 | 输出目录（默认 tests/at） |
| `--include-dirs` | 否 | 只扫描指定子目录（如 dfm-base apps） |
| `--target-lang` | 否 | 翻译目标语言（默认 zh_CN） |
| `--compile-commands` | 否 | compile_commands.json 路径（自动检测） |

**输出文件**

| 文件 | 说明 |
|------|------|
| `scanned_ok.yaml` | 有 objectName/accessibleName 的 UI 类 |
| `scanned_gaps.yaml` | 缺少名称的 UI 类 |
| `element_gaps.yaml` | 交互元素缺失 accessible_id 报告 |

**扫描能力**

- `setObjectName("字面量")` 直接捕获
- `Utils::set_Object_Name(this)` 模式推断（class_name → objectName）
- `tr()` / `QStringLiteral()` / `translate()` 国际化文本解包
- `new QAction(tr("text"))` QAction 文本捕获
- `.ui` XML 文件解析（widget 树 + action）
- `.ts` 翻译文件查找（支持命名空间剥离匹配）
- `compile_commands.json` 自动检测和使用（推荐，大幅提升解析准确度）

### 2. record — 事件驱动录制

实时捕获 AT-SPI 事件（focus/window/children-changed）和输入事件（鼠标/键盘），组织成 segments，输出 record_session.yaml。

```bash
# CLI 模式（终端控制）
youqu at record \
  --app deepin-terminal \
  --launch /usr/bin/deepin-terminal \
  --output tests/at

# GUI 模式（PyQt6 浮动窗口）
youqu at record \
  --app deepin-terminal \
  --launch /usr/bin/deepin-terminal \
  --output tests/at \
  --gui

# 按模块录制（显示录制指引）
youqu at record \
  --app deepin-terminal \
  --launch /usr/bin/deepin-terminal \
  --output tests/at \
  --module tabbar \
  --plan tests/at/plan.yaml
```

**参数**

| 参数 | 必填 | 说明 |
|------|------|------|
| `--app` | 是 | 应用 ID |
| `--launch` | 否 | 启动命令 |
| `--output` | 否 | 输出目录（默认 tests/at） |
| `--gui` | 否 | GUI 模式 |
| `--module` | 否 | 模块 slug（配合 plan.yaml 显示录制指引） |
| `--plan` | 否 | plan.yaml 路径（默认 tests/at/plan.yaml） |

**CLI 操作**

- 按 `s` + Enter 创建新 segment
- 按 `q` + Enter 或 Ctrl+C 结束录制

**输出文件**

| 文件 | 说明 |
|------|------|
| `record_session.yaml` | 录制会话（segments + events） |
| `states/*.yaml` | AT-SPI 树快照 |

**事件类型**

| 事件 | 说明 |
|------|------|
| `launch` | 应用启动 |
| `window_activate` | 窗口激活 |
| `window_create` | 子窗口创建 |
| `click` / `right_click` / `middle_click` | 鼠标点击（含 hit_test 元素） |
| `type_text` | 键盘输入聚合 |
| `key_press` | 非打印键 |
| `menu_open` / `context_menu_open` | 菜单打开（区分主菜单/右键菜单） |
| `menu_close` | 菜单关闭 |
| `focus` | 焦点切换 |

### 3. merge — 分层合并

将 scan 输出与 record 输出合并为 at-tree.yaml，分离持久层和瞬态层。

```bash
youqu at merge \
  --app deepin-terminal \
  --scan tests/at \
  --record tests/at \
  --output tests/at
```

**参数**

| 参数 | 必填 | 说明 |
|------|------|------|
| `--record` | 是 | record 输出目录 |
| `--app` | 否 | 应用名 |
| `--scan` | 否 | scan 输出目录（含 scanned_ok.yaml） |
| `--output` | 否 | 输出目录 |
| `--no-clean` | 否 | 跳过录制数据清洗 |

**输出文件**

| 文件 | 说明 |
|------|------|
| `at-tree.yaml` | 合并后的 AT-SPI 树（v2.0: tree + transient_contexts） |
| `element_gaps.yaml` | 元素缺失报告 |

**at-tree.yaml v2.0 结构**

```yaml
version: "2.0"
app: deepin-terminal
tree:                    # 持久层 — 始终可见的元素
  - role: application
    name: deepin-terminal
    children: [...]
transient_contexts:      # 瞬态层 — 右键菜单、对话框、子窗口
  - id: right_click_menu_000
    trigger: {...}
    items: [...]
    is_context_menu: true
```

### 4. plan — 模块录制计划

从 cases_raw + 帮助手册生成按模块的录制计划。

```bash
youqu at plan \
  --cases tests/at/cases_raw.yaml \
  --docs tests/at/docs \
  --app deepin-terminal \
  --output tests/at
```

**参数**

| 参数 | 必填 | 说明 |
|------|------|------|
| `--cases` | 是 | cases_raw.yaml 路径 |
| `--docs` | 否 | 帮助手册目录（来自 youqu at docs） |
| `--app` | 否 | 应用名 |
| `--output` | 否 | 输出目录 |

**输出文件**

| 文件 | 说明 |
|------|------|
| `plan.yaml` | 机器可读模块列表（含录制指引和状态） |
| `plan.md` | 人类可读录制说明 |

**plan.yaml 结构**

```yaml
app: deepin-terminal
modules:
  - slug: tabbar
    name: 标签栏
    case_count: 5
    case_ids: ["test_tab_001", ...]
    recording_guide: "..."
    status: pending        # pending → recorded → merged → verified
```

### 5. parse — 用例格式转换

从 xlsx/csv 转换为 cases_raw.yaml。

```bash
youqu at parse \
  --input cases.xlsx \
  --output tests/at/cases_raw.yaml
```

### 6. tree-info — AI 标注用结构化导出

将 at-tree.yaml 转换为 AI 友好的紧凑格式，用于 LLM 标注。

```bash
youqu at tree-info \
  --at-tree tests/at/at-tree.yaml \
  --output tests/at/at-tree-annotated.yaml \
  --format yaml
```

### 7. split — 按模块分片

将 cases_raw + at-tree 按模块拆分为子目录。

```bash
youqu at split \
  --cases tests/at/cases_raw.yaml \
  --at-tree tests/at/at-tree-annotated.yaml \
  --output tests/at/modules/
```

### 8. docs — 导入帮助手册

从 deepin-manual 导入应用帮助手册章节。

```bash
youqu at docs deepin-terminal --output tests/at/docs
```

### 9. precandidate — 选择器预筛选

基于约束规则为每个用例步骤预筛选候选元素，减少 LLM 映射负担。

```bash
# 全量模式
youqu at precandidate \
  --cases tests/at/cases_raw.yaml \
  --at-tree tests/at/at-tree-annotated.yaml \
  --output tests/at/suite-cases.yaml

# 按模块模式
youqu at precandidate --module-dir tests/at/modules/tabbar/
```

**规则**

- 菜单类型自动分类：右键关键词 → `dtk_context_menu`，标题栏关键词 → `dtk_main_menu`
- 角色到操作的映射：button → click，text → type，list → click 等
- 关键词匹配评分：name/comment/accessible_id 与步骤描述的相似度

### 10. validate — 分层验证

5 个 gate 分层验证管线产物质量。

```bash
# 全部 gate
youqu at validate --gate all \
  --at-tree-annotated tests/at/at-tree-annotated.yaml \
  --suite-cases tests/at/suite-cases.yaml \
  --cases-mapped tests/at/cases_mapped.yaml \
  --generate-output tests/at/yaml/ \
  --element-gaps tests/at/element_gaps.yaml

# 单个 gate
youqu at validate --gate 1 --at-tree-annotated tests/at/at-tree-annotated.yaml
```

**Gate 说明**

| Gate | 名称 | 验证内容 |
|------|------|----------|
| 1 | 元素覆盖率 | at-tree 中交互元素是否有 accessible_id |
| 2 | 候选完整性 | suite-cases 中每个步骤是否有候选元素 |
| 3 | 映射正确性 | cases_mapped 中 selector 是否在 at-tree 中存在 |
| 4 | 生成完整性 | generate 输出的 YAML 是否引用了存在的元素 |
| 5 | 语义安全 | description-as-input、缺失前置条件、空 selector |

### 11. generate — 生成可执行 YAML

从 cases + mappings/at-tree 生成可执行的 YAML 测试套件。

```bash
youqu at generate \
  --cases tests/at/cases_mapped.yaml \
  --output tests/at/yaml/ \
  --app deepin-terminal \
  --at-tree tests/at/at-tree.yaml
```

### 12. run — 执行测试

```bash
# 执行全部
youqu at run --testdir tests/at/yaml/

# 按 suite 执行
youqu at run --testdir tests/at/yaml/ --suite menu_test_suite

# 关键词过滤
youqu at run --testdir tests/at/yaml/ -k "标签页"

# 跳过环境检查
youqu at run --testdir tests/at/yaml/ --skip-env-check
```

### 13. smoke — 模块烟雾测试

每个模块运行 1 个代表 case，验证运行时可寻址性。

```bash
# 全部模块
youqu at smoke --modules-dir tests/at/modules/

# 单个模块
youqu at smoke --module-dir tests/at/modules/tabbar/
```

### 14. verify — 单 case 深度验证

```bash
youqu at verify \
  --suite tests/at/modules/tabbar/tabbar.suite.yaml \
  --spec-id tabbar_s0
```

## 完整工作流示例

### 按模块模式（推荐）

```bash
# 1. 扫描源码
youqu at scan --src /path/to/app/src --app my-app --output tests/at

# 2. 解析用例
youqu at parse --input cases.xlsx --output tests/at/cases_raw.yaml

# 3. 导入帮助手册
youqu at docs my-app --output tests/at/docs

# 4. 生成录制计划
youqu at plan \
  --cases tests/at/cases_raw.yaml \
  --docs tests/at/docs \
  --app my-app \
  --output tests/at

# 5. 按模块录制（循环）
youqu at record \
  --app my-app \
  --launch /usr/bin/my-app \
  --output tests/at \
  --module tabbar \
  --plan tests/at/plan.yaml
# → 操作应用 → 按 q 结束

# 6. 合并 scan + record
youqu at merge \
  --app my-app \
  --scan tests/at \
  --record tests/at \
  --output tests/at

# 7. 导出 AI 标注用结构化树
youqu at tree-info \
  --at-tree tests/at/at-tree.yaml \
  --output tests/at/at-tree-annotated.yaml

# 8. 预筛选候选元素
youqu at precandidate \
  --cases tests/at/cases_raw.yaml \
  --at-tree tests/at/at-tree-annotated.yaml \
  --output tests/at/suite-cases.yaml

# 9. 验证（LLM 映射后）
youqu at validate --gate all \
  --at-tree-annotated tests/at/at-tree-annotated.yaml \
  --suite-cases tests/at/suite-cases.yaml

# 10. 生成可执行 YAML
youqu at generate \
  --cases tests/at/cases_mapped.yaml \
  --output tests/at/yaml/ \
  --app my-app

# 11. 烟雾测试
youqu at smoke --modules-dir tests/at/modules/

# 12. 执行测试
youqu at run --testdir tests/at/yaml/
```

### 全量模式（快速验证）

```bash
youqu at scan --src /path/to/src --app my-app --output tests/at
youqu at record --app my-app --launch /usr/bin/my-app --output tests/at
youqu at merge --app my-app --scan tests/at --record tests/at --output tests/at
youqu at tree-info --at-tree tests/at/at-tree.yaml --output tests/at/at-tree-annotated.yaml
youqu at precandidate --cases tests/at/cases_raw.yaml \
  --at-tree tests/at/at-tree-annotated.yaml --output tests/at/suite-cases.yaml
youqu at generate --cases tests/at/cases_mapped.yaml --output tests/at/yaml/ --app my-app
youqu at run --testdir tests/at/yaml/
```

## 常见问题

### scan 失败率高

- 使用 `compile_commands.json`：`--compile-commands /path/to/build/compile_commands.json`
- 确认 libclang 版本与 Python bindings 匹配：`python3 -c "import clang.cindex; clang.cindex.Config().set_library_file('/usr/lib/llvm-18/lib/libclang.so.1')"`

### .ts 翻译文件未加载

- .ts 文件通过递归搜索查找，确保文件在源码目录的任意子目录中
- 文件名需匹配 `*_zh_CN.ts` 格式
- 可用 `--target-lang` 指定其他语言

### record 点击元素为空

- 确保 AT-SPI 可访问性已启用：`QT_LINUX_ACCESSIBILITY_ALWAYS_ON=1`
- 使用 `--launch` 参数让框架自动设置环境变量并启动应用
- filler 容器已修复会递归子节点，但仍可能遇到 DTK 不暴露的控件

### Wayland 录制精度低

- Wayland 下 evdev 只能通过相对位移重建鼠标坐标，精度有限
- 可降级为纯 AT-SPI focus 事件模式（不依赖坐标）

### plan 状态不更新

- 录制结束后自动更新为 `recorded`
- merge/generate 后需手动更新或后续版本自动更新

## 技术架构

### 分层设计

```
持久层 (tree)          → 始终可见的元素 (launch + window:activate 合并)
瞬态层 (transient)     → 右键菜单、对话框、子窗口 (不混入主树)
静态注入 (scan)        → objectName、accessibleName、action_texts、翻译文本
```

### 菜单分类二分规则

```
右键关键词 (右键/right-click/context menu) → dtk_context_menu
标题栏关键词 (主菜单/标题栏/menu bar)       → dtk_main_menu
默认                                       → dtk_context_menu (更通用)
```

### X11 / Wayland 双协议

| 能力 | X11 | Wayland |
|------|-----|---------|
| 键鼠监听 | XRecord (被动) | evdev (需 root/input 组) |
| 窗口信息 | xdotool + xwininfo | libdtkwmjack (CTypes FFI) |
| 精度 | 高 | 低 (相对位移) |
